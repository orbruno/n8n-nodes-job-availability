# Changelog

All notable user-visible changes are recorded here.

## 0.2.0 - 2026-08-28

- Enabled the Job Availability node for use as an n8n AI Agent app tool.
- Added a constrained Posting / Observe agent example with fixed operation and idempotency boundaries.
- Documented safe tool configuration and the human-review requirement for durable mutating operations.

## 0.1.1 - 2026-08-28

- Updated the public maintainer email so the n8n Creator Portal can deliver package ownership verification.

## 0.1.0 - 2026-08-27

- Added the Job Availability API credential and authenticated readiness test.
- Added declarative Posting, Availability Run, and Job resources.
- Added explicit and scheduled run creation, run lifecycle, and job availability operations.
- Added synthetic example workflows, package tests, inspection scripts, and release documentation.
